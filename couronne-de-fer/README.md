# Couronne de Fer

Jeu de stratégie en temps réel dans le navigateur, inspiré d'Age of Empires : un seul fichier HTML, sans dépendance.

Ouvrez `index.html` dans un navigateur pour jouer.

## Contenu

- **Économie** : nourriture (baies, fermes), bois, or, pierre ; villageois qui récoltent et rapportent aux dépôts (Hôtel de ville, moulin, entrepôt).
- **Bâtiments** : maison, moulin, entrepôt, ferme, caserne, camp de tir, écurie, tour de guet, atelier de siège.
- **Trois âges** : Âge sombre, Âge féodal, Âge des châteaux ; chacun débloque de nouvelles unités.
- **Unités** avec bonus de contre : épéiste, piquier (anti-cavalerie), archer, cavalier (anti-archers), catapulte (anti-bâtiments, dégâts de zone).
- **IA adverse** qui développe son économie, franchit les âges, défend sa base et lance des vagues d'attaque. Trois niveaux de difficulté.
- Brouillard de guerre, mini-carte, points de ralliement, groupes de contrôle, commandes tactiles.

## Commandes

| Action | Souris / clavier |
| --- | --- |
| Sélectionner | Clic gauche, glisser pour encadrer, double-clic pour tout le type |
| Ordre contextuel | Clic droit (déplacer, récolter, construire, réparer, attaquer, ralliement) |
| Caméra | Flèches, clic milieu ou Espace + glisser, molette pour zoomer, mini-carte |
| Raccourcis | `H` Hôtel de ville, `.` villageois inactif, `Ctrl+1–9` groupes, `P` pause, lettres affichées sur les boutons |

Victoire : détruire l'Hôtel de ville ennemi et toutes ses unités.
